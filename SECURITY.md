# Security policy

## Project status

Mayanna–HashMin is an incomplete, unaudited research prototype. No release is currently designated as production-supported. The paper's construction and security arguments do not establish the security of the code in this repository. The [README](README.md#implementation-status) records known implementation gaps.

## Reporting a vulnerability

Send security-sensitive findings privately to **mayankmuthanna.m@gmail.com** with the subject `Mayanna-HashMin security report`. Include the affected commit, relevant component, expected and observed behaviour, impact and a minimal reproduction using synthetic data. Do not send real credentials or private keys.

Please avoid publishing an exploit or sensitive details in a public issue before the maintainer has had an opportunity to investigate. Ordinary documentation corrections and already-public implementation limitations may be discussed in issues. Response and remediation times are not guaranteed.
